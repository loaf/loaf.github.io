用1万亿个Token训练出一个国家主权大模型

loaf 2026-09-04 大约 9 分钟 随笔 人工智能 LLM AI

相信大家都听过一个段子：福建的法官面对一个欠钱不认的老赖，发出灵魂拷问：“你敢对妈祖发誓你没有借他的钱？”，老赖立马认输。

这几天AI界再现了此名场面。沙特的AI公司HUMAIN宣布发现了一个阿拉伯语的大模型 Humain M3，声称100%沙特模型。

然后马上有人发帖评论：

不过，后面又补充道，他们使用了超过1万亿个阿拉伯语Token进行后训练。

平心而论，这比巴西的那个模型技术含量要高的多，而使用1万亿个Token进行的后训练，从量上来看，已经不是普通的后训练方式了。可以算是“继续预训练”或者“中训练”了。

今天我们借这事谈谈“深度后训练”这门手艺，顺便聊聊它背后更大的棋局。

为什么选MiniMax，而不是更有名的DeepSeek或者GLM？

这个可没有官方说明，不过我们可以猜一下。

第一，HUMAIN想要的，正是M3所擅长的。

MiniMax M3 是当前最强开源模型之一，原生多模态。HUMAIN后训练的重点是“工具调用、电脑操作”这些能力，而这正是M3的设计目标。相比较而言，DeepSeek重在推理和成本，GLM则侧重代码能力。

第二，王爷也是会算账的。

一般来说，模型的参数越大，需要的显卡就越多。但这主要是指训练成本。对于MoE架构的模型来说，在推理时需要的显卡数量与激活参数关系更大。

M3是MoE架构，总参数不是最少的，但每次激活的量是230亿，相对于同期的DeepSeek和GLM是最少的。主权 AI 意味着沙特要在全国自建推理集群，激活参数小一截，电费和显卡就省一圈。

对于“头顶一块布，天下我最富”的王爷们来说，钱也许不是问题，但是卡就不一定能买的到了。所以M3是更合理的选择。

第三，本来就是MiniMax的金主。

MiniMax港股上市时，重要投资方里就有阿布扎比主权基金。可以说沙特本是MiniMax的金主之一。前段时间上海WAIC，沙特官方团队也专门为MiniMax站台了。这次选择M3为基座，也算是肉烂在锅里了。

1万亿个 Token，是怎么灌进去的？

用1万亿Token在一个开源基座模型上进行后训练，绝非简单的“喂数据”，而是一个系统工程：

第一步：继续预训练

我们通常说“后训练”，主要是教模型“规矩”而不是“知识”。所以指令的量不会太多，而这次沙特官方明确提到了1万亿个Token这个数字，说明它已经不是常规的模型SFT了。

前面我们说过后训练相当于大学生毕业后的上岗实习，而这个1万亿的量级，相当于“重新上一遍大学了”。这个事实反过来说明：阿拉伯语在原基座的语料里占比极低，几乎要整门语言重灌。

首先需要明确的是，“继续预训练”的目标和普通的“预训练”是一样的，还是预测下一个词，架构什么的都不变。

唯一的区别在于，预训练是在平地上建大楼，而继续预训练是在封顶的大楼里做内部装修：墙不能砸，梁不能动，锤子都不敢抡太重，因为楼里已经住着中英文和代码这些老住户。

在工程上，这相当于戴着镣铐跳舞，而且是三副镣铐。

镣铐一：学习率，步子迈多大是个问题

预训练的学习率遵循一条完整的日程表：升温、爬坡、再一路退火到尾声。继续预训练接手的，是一张已经退火完毕的权重。这时学习率给大还是给小，学界认真研究过。

步子迈的大，模型学阿语学得快，但大步幅会把旧权重里的中英文和代码表征踩乱，遗忘加剧；步子给小，稳当，但新语言学得慢，1 万亿 Token 的预算可能烧不出该有的效果。

总结一下关于重新预训练的论文12，结论很直白：学习率抬多高，决定了你在"新语言收益"和"旧能力损失"之间站在哪个点上，没有免费的午餐。

根据上面的论文，常见的做法是把学习率压到预训练峰值以下一个量级左右，再配一段很短的 升温(warmup)，像给手术台上的病人用最小有效剂量的麻药。

镣铐二：回放配方，数据比例是得靠经验

数据配方也不是纯阿语。新闻、书籍、维基、宗教典籍、方言语料，加合成数据，还要混入一定比例的中英文语料做"回放"（replay）。原因还是灾难性遗忘：神经网络的记性是挤占式的，新语言灌得太猛，旧能力会被冲走。混旧课本进去，相当于边学阿语边复习中英文，防止捡了芝麻丢了西瓜。

但"回放多少"从来不是拍脑袋。上海人工智能实验室的研究3证明，混合语料里各部分的比例对模型最终损失的影响，可以用缩放律定量地拟合出来。换句话说，“多少阿语配多少英文"原则上是可以算的，只是每个基座都得重新算一遍。

工业界的对应做法见 Llama 3 的技术报告：把继续预训练拆成多个阶段，中途按配比换料，最后一段低学习率退火期集中喂最高质量的数据4。

顺带一提，Code Llama 是这条路线最著名的公开案例：在 Llama 2 的基础上用约 5000 亿代码 Token 续训，中途还换了训练目标（先填空后长上下文），硬生生把一个通用模型改造成代码专才5。继续预训练能把模型改造到什么程度，它就是活证据。

镣铐三：词表，出生时定死的刀法

第三副镣铐藏得最深，就是分词器（tokenizer）。

分词器是预训练开始前就冻结的组件，词表里有什么、怎么切，后训练阶段动不了它。学界用"生育率”（fertility）这个有点怪的词衡量刀法好坏：平均一个词要被切成几个 Token。Petrov 等人 2023 年的研究系统展示了 tokenizer 的语言不公平：同一段文本，不同语言的 Token 开销可以差出好几倍，而 Token 开销会直接换算成训练成本、推理账单和有效上下文长度6。MiniMax 的刀法为中英文打磨，切阿语就是钝刀子割肉。

有没有根治的解法？有，中文社区早就趟过这条路。Chinese-LLaMA-Alpaca 的做法是给 Llama 扩充中文词表，重新初始化词嵌入层并优先单独训练，其余参数保持冻结7。但代价明摆着：扩词表会改变模型结构，embedding 矩阵的尺寸都变了，模型从此不再是"那个"基座。

HUMAIN 的选择很能说明问题：它的模型与 MiniMax M3 架构、参数完全一致，这意味着它大概率没有动过词表（这一步是我的推断，官方未披露）。也就是说，它宁可长期消化 tokenizer 的钝刀，也要保住"与基座同构"这个身位。为什么？同构意味着未来基座升级时，整条后训练管线可以原样搬过去；动了词表，每次升级都要重做一次 embedding 手术。

有没有不疼的改法？

学术界还给过一个更优雅的设计：LLaMA Pro 的"块扩展"（block expansion）。把预训练好的 Transformer 块全部冻结，在层间插入若干新块，新块初始化为恒等映射，等于什么都没加，然后只训练新块。旧知识一个字节不动，新知识全写在新块里8。

听起来完美，代价也诚实：参数量变大了，推理成本跟着涨，而且模型结构同样偏离了基座。所以 HUMAIN 走的大概率还是最朴素也最累的那条路：全参数、低学习率、带回放的继续预训练。没有巧劲，全是苦功。

这条路的效果可以参照 KAUST 的 AceGPT，他们此前用 Llama 2 做过阿语续训，报告的观察很诚实：阿语能力上去了，英文和指令跟随能力小幅回撤，要靠后续的 SFT 和 DPO 拉回来9。1 万亿 Token 灌下去，HUMAIN 的工程师要在同一座天平上再称一次。

第二步：监督微调（SFT）

这一步其实就进入传统后训练工作区域了，如果说“继续预训练”是让大学生重修阿拉伯语课，SFT 就是请老师一对一示范：用户这么问，你这么答。这个阶段数据量不大，关键在质量不在数量。一道解法漂亮的数学题，胜过一万道重复的问答。

第三步：偏好优化与强化学习

这也是我们熟悉的内容了，RLHF、DPO 什么的，本质是给模型的行为立规矩。让模型变得阿拉伯化：标准阿语的语法与敬语，宗教用语规范，伊斯兰语境下什么该说、怎么说。按沙特人的说法就是，要符合“伊斯兰价值观”。

最后再叠加一层智能体方向的强化学习：工具调用、操作电脑、多步任务。让模型能像一个真正的阿拉伯人一样在沙特的政府和商务系统里干活。

训练好的模型和原版有什么不同？

怎么说呢？简单类比一下就是：躯体没变，灵魂换了。用修仙的术语就是：夺舍。

架构和参数量与基座完全一致，还是那个 4280 亿总参、230 亿激活的 MoE，变的是行为分布。阿语从"能听懂"变成"母语级输出"；知识框架里长出了阿拉伯本地的文化坐标。

不过，毕竟是寄生的，总还是有点不足之处：

主要就是分词器的问题，因为分词器是预训练时定死了的，MiniMax训练用的语料大多为中英文，有论文证明，用MiniMax的分词器来切阿拉伯语，效果更差，只能往细里切，代价是推理更贵，有效上下文变短，学习效率变低。

但是沙特人对这点明显不太在乎，毕竟得到的好处更多。

最大的好处就是价值观对齐。沙特人明显更在乎“伊斯兰价值观”。

但我更感兴趣的是另一个附带红利，在以前关于语料的文章里我提到了，跨语言迁移会带来能力上的提升。只是我没有找到有用的对比数据。

MiniMax有什么好处？

权重是开源的，白送，MiniMax 图什么？

其实MiniMax还是有好处的。

第一层是直接收入。基座权重是免费的，但是在此基础上后训练，总还是有API收入的，加上商业授权、定制训练、部署支持等，都是生意。按王爷们的调性，那些运维生意，总是能吃到的。

第二层是生态。Minimax的开源权重已经衍生出多个社区模型，在此基础上的改进和插件不计其数。而且根据Minimax的财报，他在B端的收入已经开始超过C端，说明商务用户已经成为MiniMax的主要收入来源。这时，沙特作为一个主权国家，公开拿它当基座模型，不是一个很好的广告吗？

基座模型升级了怎么办？

再回到技术。

开源世界有个规律：大版本是从头重训，小版本是在老权重上续训。

对 HUMAIN 来说，好消息是后训练攒下的资产大部分可以复用：阿语语料、数据管线、SFT 数据、评测集、RL 环境，都能原样搬到新基座上重跑。1 万亿 Token 的后训练成本，远低于从零预训练。装修队可以换栋楼继续干活。

坏消息是必须一直追。如果 MiniMax 换了分词器或者改了架构，迁移成本就会上升；不追，就只能用旧基座，性能就跟不上前沿模型了，这就有点配不上王爷们的身份了。

学界也在想辙。有一路研究计算后训练前后的"权重差"，把这份差值直接加到新基座上，据称能恢复直接训练约 95% 的性能；LoRA 适配器的跨版本迁移也在探索。都是前沿，都不成熟。

尾声：Token出海是一种国家战略

最后，让我们升华一下。

Token出海，不仅仅是出售算力，还可以是一种技术标准和习惯的培养。

Linux和Android珠玉在前，免费送出内核，生态会自己长出来，而生态的迁移成本是最深的护城河。

当一个国家的数据管线、评测体系、工具链、工程师的习惯，全都长在某个基座上，“换基座"三个字就等于推倒重来。

所以当越来越多的主权国家选择中国基座，输出就不只是权重，还有标准、习惯和技术亲缘。开源基座，是一种战略投资。
