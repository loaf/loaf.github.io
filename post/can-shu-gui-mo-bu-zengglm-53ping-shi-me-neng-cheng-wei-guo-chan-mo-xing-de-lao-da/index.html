参数规模不增，GLM-5.3凭什么能成为国产模型的老大？

loaf 2026-08-15 大约 9 分钟 随笔 人工智能 LLM GLM

8月14日，在DeepSeek V4 Pro发布的第二天，智谱发布了 GLM-5.3。官方博客的第一句话就是：

“Scaling post-training is all we did for GLM-5.3."（后训练 Scaling，是我们为 GLM-5.3 做的全部事情。）[1]

这句话的分量在于它的"控制变量”。GLM-5.3 和 GLM-5.2 相比：架构没变。参数没变。总参数和激活参数，一个数字都没动。1M 的上下文长度也没变[2]。

变的只有一样东西：后训练（post-training）。 这正是对标题疑问的回答。

一、什么是后训练：读完大学，还要上岗实习

一提到后训练，知道一点AI的人往往马上想到一个缩语：RLHF。没错，就是人类偏好的强化学习（Reinforcement Learning from Human Feedback），当年这个词第一次进入我们视野时，是OpenAI用它来训练ChatGPT，让ChatGPT的回答更像一个受到教育的、有正确价值观的人类：说话要有礼貌、别教人干坏事……

从前沿的闭源模型中，我们也就学到这些概念，所以认为后训练更像是一门礼仪课，重要性没那么高。

但是这次国产模型做的事（包括DeepSeek V4正式版相对与预览版），就是把这层窗户纸给揭穿了，让我们不光发现，后训练也能创造奇迹。还能了解后训练到底是训练了一些什么。

先说清概念：

预训练（pre-training）像读书：模型把互联网上的海量文本读一遍，学会语言、知识和常识。这一步决定它知道什么。后训练像上岗实习：给它真实的任务，让它动手做，做对了给正反馈，做错了给负反馈，成千上万轮练下来。这一步决定它会做什么。


上图中，预训练决定"知道什么"，后训练决定"会做什么"。GLM-5.3 改动的，只是右侧环节。

关键在于：后训练不添加新知识，它是在唤醒知识。DeepSeek 的技术报告里有一个很准确的词——后训练"解锁（unlock）“并进一步增强模型能力[3]。智谱说得更直白：同样的基座，“可能我们还远未开发出这个基座的智能上界”[2]。

换句话说，模型可能早就"知道"怎么做好一件事，只是从来没人用正确的方式逼它练过。

二、从怀疑到同意“后训练远比想象的重要”

当GLM 5.3发布得分时，大家的第一反应是怀疑。但是很快就是第三方的证据证实了它的能力。

不仅仅是智谱的GLM，DeepSeek的V4也是这样，它的正式版也是在预览版基座不变的前提下，通过后训练来进行优化。

美国分析师 Nathan Lambert 在他的 newsletter Interconnects 上写了一篇被广泛转发的分析，标题起得很妙——“Hint: It’s really not a distillation story”（提示：这真不是一个蒸馏故事）[4]。他的判断是：智谱的博客表述与一个"以 RL 为主导的训练范式"完全吻合，因为 RL 环境、运行环境的大规模基础设施、以及有效混合它们的算法，是无法从别人的模型里蒸馏出来的。他对这些分数的结论也很干脆：“the real deal”（真实可信）。

现在业界已经公认：“后训练远比想象的重要”。

DeepSeek-V4-Pro 的官方模型卡把 GLM-5.2 列为对照模型，而 GLM-5.3 的官方表格里也列着 DeepSeek-V4-Pro-0813，两家在后训练这条赛道上，公开互为参照系。

这就是开源的好处：秘密变成了公共知识。

三、唐杰的"旋钮论”：Scaling 从来不止一个旋钮

前几天，智谱 CEO 唐杰就GLM-5.3发布在X上有一个贴文《Thoughts About Scaling Law》[5]

他讲了一个行业反思的故事：

第一幕，参数迷信。2020 年的 Kaplan Scaling Law 建议参数增长快于数据，行业照做，一路卷到 5300 亿参数的模型。唐杰的定性毫不留情：“万亿参数那一轮，是行业集体走的一段弯路，然后又集体折返。”

第二幕，两次修正。2022 年 Chinchilla 用 400 个模型重做实验，证明参数和数据应该同速增长；此后推理成本入局，模型每天被调用数十亿次，最优解转向"更小的模型、训练更久"。参数这个旋钮，被拧过头了。

第三幕，MoE 总数和激活数平衡。到了混合专家架构时代，“总参数"约等于模型的记忆容量，而真正决定推理深度的是激活参数和有效深度。他以漏洞发现为例：

发现一个漏洞不是检索问题。它不来自记住更多 CVE；它来自把一条二十步的推理链完整带到终点而不丢失线索。这个能力不在总参数里。

所以他的结论是：模型能力是很多个旋钮的联合函数——你有多大数据？计算花在哪？在什么条件下运行？而"下一个值得转的旋钮，很少是上一个值得转的”。

GLM-5.3 就是这个理论的一次公开实验：所有旋钮都不动，只拧"后训练"这一个。不是因为它最重要，而是因为当下它"余量最大（most slack）


上图正是唐杰的比喻——能力是多旋钮的联合函数；这一轮国产模型只拧了"环境"和"奖励"这两个（后训练旋钮），收益却“不是边际的”。

你可能会问：为什么不把所有旋钮一起拧？当然可以，但一起拧你就说不清成绩该归谁。

四、窗户纸后面到底有什么：把后训练拆开给你看

好，重点来了。以前我们说"后训练"，就是知道了一个术语，具体怎么做的，语焉不详。

这次智谱和DeepSeek两家公司不一样，他们把配方摊在了桌面上。细节我尽量少讲，这里只提三个关键词。

关键词一：可验证奖励

后训练的主流打法是强化学习（RL）：让模型做题，做对给奖励。麻烦在于——谁来判断"做对了"？

老办法是人给答案打分，或者训一个奖励模型学人类偏好。这就上面提到RLHF。工作量大不说，准确度也差。

如果你看过我以前的文章，有一篇关于Fable 5为什么强的文章，提到过后训练，当时我认为自动打分功能只在预训练中有用，在后训练中只能通过大量高质量的人类员工来工作。现在看来，我还是缺乏想象力了。


上图是一个可验证奖励的RL循环。DeepSeek 造了专门的 DSec 安全沙箱[3]；智谱的验证器要通过"标准答案 / 空操作 / 未解决"三道检查才上岗[1]。

这一步的工程量远比听起来重。DeepSeek 为此造了一整套跑 RL 训练环境的沙箱基础设施；智谱更进一步，用流水线批量合成训练环境——研究型 Agent 从真实工作里收集任务模式，转化成可运行的多步骤任务；裁判 Agent 先把每道题做一遍，确认题目真的可解；验证器在拿不到参考答案的情况下生成，再专门派"解题 Agent"去钻奖励规则的空子，钻出来一个堵一个。

你没看错：他们连"模型学会作弊怎么办"都写进了流程。

关键词二：环境规模化——从习题册到真实工作

这是 GLM-5.3 这次最核心的增量，智谱的原话是：训练任务不再只是"传统的编程题"，而是**“专家在真实工作中承担的完整专业工作单元”**，有些任务相当于一位资深工程师好几天的的工作量[1]。

举个例子你就懂了。给模型一个机器学习基础设施任务：计算集群、存储系统、内部文档、代码库、历史实验结果，要求它端到端地诊断训练系统的瓶颈、实施优化、跑实验、交付一个可度量的提速，还得保证正确性。就是把模型当成一个真实的算法工程师，让它解决所有真实环境中可能遇到的问题。

这和"写个函数通过单元测试"是两种完全不同的能力。前者练的是独立完成工作，后者练的是完成指令。环境规模扩了数十倍，模型练的东西就变了质。

以前你刷题，能刷出一个高分，现在直接给你一个任务，完成了才合格，这可是完全不同的考核方式。对于一个AI大模型来说，以前你只要知道算法、语法，就能完成任务，现在不光要会算法语法，还得面对网络中断、数据错误等物理环境中才可能碰到的奇奇怪怪的问题。

关键词三：算法和基建，全都有论文

上面这些东西全部有公开论文和开源代码。智谱用于 GLM-5.2（也就是 GLM-5.3 的基座）RL 训练的算法 SAO 和 CompactionRL，都有 arXiv 论文，白纸黑字写着"已部署于 GLM-5.2（750B-A40B）的训练管线"，连超参数都给了[6][7]；训练框架 slime 直接开源在 GitHub 上[8]。DeepSeek-V4 的两阶段后训练范式（先分领域练出专家，再用十几个"教师模型"在线蒸馏合并）写进了技术报告，报告本身还附 MIT 协议开源了全部权重[3]。

以前的"后训练"是新闻稿里的营销名词，现在的后训练是有公式、有超参、有仓库的一门工程学。

顺便说一个最有戏剧性的副产品。智谱在训练里加入了漏洞挖掘的环境，本意只是让模型多懂点安全，结果"能力发展的速度超出我们预期"：模型开始能把一条利用链的十几个阶段串起来，形成完整的攻击计划。实战成绩：联合安全团队在 269 个真实项目里挖出 2,436 个漏洞，1,097 个中高危，最老的一个从 1981 年潜伏至今，平均"坑龄"26.6 年，连 Cursor 和 DNS 协议四十年的老漏洞都被翻了出来。DeepSeek 那边也一样，Cybergym 分数从 38.7 飙到 76.7。

用智谱自己的话说：“能力增长最快的方向，恰是我们落后最多的方向。”

五、更多的可能性

从唐杰的那篇推文我们得知：过去我们习惯把 AI 性能粗暴地换算成三个数：参数多大、数据多少、算力多少。

但这并不是真相。实际上，参数是一个旋钮，数据是一个旋钮，推理算力是一个旋钮，而环境、奖励、算法、蒸馏、课程安排，每一个都是可以单独拧的旋钮。

唐杰的旋钮论有趣的地方在于，他还提供了更多的可能性：下一步可能会去拧另一个，也许是中训练也许是预训练。

或者更粗暴一点，我们用更大的力去扭这个旋钮会怎么样？后训练自己会有Scaling Law 吗？

尾声

我们以前相信天赋（参数），后来相信阅读量（数据），现在终于开始认真研究教学法（后训练）。这大概是最有意思的一件事：AI 的进步方式，开始越来越像人类的进步方式了。

同一个大脑，不同的练法，可以差出数倍的人生。
