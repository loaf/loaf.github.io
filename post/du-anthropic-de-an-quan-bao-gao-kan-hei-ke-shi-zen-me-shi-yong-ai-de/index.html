读《Anthropic的安全报告》，看黑客是怎么使用AI的

loaf 2026-09-12 大约 5 分钟 随笔 人工智能 AI 安全

周末在家读Anthropic前天发布的安全报告1。

AI是一个强大的工具，而最新技术往往总是被灰产最新利用。

随着AI Agent的发展，大模型不仅仅有大脑，也开始有了手脚。所以，黑客们在使用AI时，已经从把AI当作“智囊”演变为让AI“动手操作”，人类仅仅监督和负责验收战果。

报告里有一个编号为GTG-10007的案例，揭示了几名本科生是如何利用AI强大的能力将黑客攻击行为由天才程序员的智力挑战变成自动化生产车间的。

据报告声称，该行动的核心操作人员为湖南长沙的几名本科生，一人曾在深信服实习，正在面试奇安信的职位。

他们做了什么

简单来说，就是用AI Agent建立一个24小时在线持续不断运行的程序，这个程序会自动在网上找网络设备的漏洞，然后自动分析漏洞，破解后自动存储数据库。就像工厂流水线一样。

这个工厂同时维护着五条并行的工作流。

  1. 漏洞利用与入侵；
  2. 外国政府网络侦察；
  3. 对主流终端安全产品的持续漏洞研究与利用开发；
  4. 恶意软件的开发与测试；
  5. 采集基础设施建设。

这五条工作流共享同一套工具与基础设施底座和持久战役记忆。

它们在运行中穿插着三个自主循环：

  1. 设备 0day 研究循环：厂商固件镜像经"专用技能（purpose-built skill）“解密、解包为根文件系统、载入反汇编与审计会话；助手 agent 通过工具服务器操作反编译器，沿反编译与交叉引用链行走（数千次反编译调用，连续的反编译调用序列占主导）；结合自建知识库和历史 PoC 形成漏洞假设；指派编写利用代码，在目标产品的实验副本上测试，迭代修改直至成功，成果进入操作者的私有漏洞组合库。一条持续迭代网络设备的流水线，单月产出十余个可能的 0day。
  2. 攻击面与 OSINT 侦察循环：扫描范围由目标行业播种 → 经专用工具服务器调用资产搜索引擎，配套指纹识别工具 → 暴露面测绘、入口点对照已知漏洞做资格判定 → 每轮结果写入持久项目记忆并自动扩大下一轮目标集。用于打击多个外国政府与外交机构，外加十多家中国国内公司。
  3. 自主采集舰队循环：13 个常驻采集 agent 按计划任务运行，从目标网站和社媒人设下载内容；手段是分层爬虫、反爬绕过、商业代理出口。相邻流水线以"情报报告体例"对内容摘要打分，交付至分发门户。

人机分工：人主要做开发、消费工作流产出，以及在自主工作流产出的入侵事件或弱凭证/暴露控制台获得的入口出现时介入；人进来之后由 AI 列举主机、经凭证复用与暴露管理面提权、收割凭证与数据、回传至操作者基础设施再横向到下一台主机。

这里有一个细节是：AI 工作流面向全球互联网，而人的亲手入侵独独集中在中国国内受害者身上。

技术上的推测

在技术细节上，我们能注意到报告中的用语，所以推测：

攻击行为是基于Claude Code，调用了MCP服务来实现IDA headless类似的反编译服务和资料搜索引擎服务。

其中谈到了一个purpose-built skill，说明市面上已经有现成的解密技能产品流通。这是一种将高技术人才的经验沉淀成可复用的技能，让AI低成本调用的模式。而这些沉淀的知识，变成了一种复利的资产，循环随时间变的越来越强。这和人类经验还不一样，对于人类，靠的是悟性和智力，而这是不能传播的。但AI不一样，它能让同类产品的漏洞发现边际成本断崖式下降。

根据报告内容，他们主要是通过解密风格安全设备和硬件防火墙的固件来挖掘0-day漏洞。这个流程就是上面提到的设备0-day研究循环。

这个流程几乎不需要人工干预：

  1. 自动获取与解包：通过脚本抓取主流厂商的设备固件，然后将目标二进制文件加载到解密工具。
  2. AI遍历审核源代码：AI 助手沿着反编译与链接引用，遍历代码，并且可以沿着函数调用链，遍历更深层次的交叉引用。
  3. 猜测漏洞：AI 结合自身的知识库，猜测可能的漏洞。
  4. 反复尝试：AI根据自己的猜测，假定漏洞存在，然后编写攻击代码在本地的虚拟靶场中自动执行攻击测试。
  5. 成功入库：根据测试反馈，修改后重试，直到成功，然后将该漏洞保存到私有漏洞库。

技术水平评估

维度 评估 依据与保留
自动化/智能体工程 高（相当于一个小型 AI 原生安全公司的产出系统） 多 agent 拆解派发、持久记忆、工具服务器、专用 skill、定时舰队、自动扩靶，全套现代 agent 工程实践
漏洞研究深度 中高，需打折 原文措辞是 “possible zero day findings”（可能 0day）且在自有 lab 验证——报告视角只能看到会话，无法独立确认这些漏洞的真实质量与野外利用成功率；但"对多国政府组织拥有的同类设备发起利用尝试"一句暗示至少部分 exploit 可用
人工入侵技战术 一般 凭证复用、暴露管理面、弱凭证，这些都是一些简单的手工操作无技术含量
数据工程 中高 13 agent 舰队 + 反爬绕过 + 代理出口 + 情报体例打分 + 分发门户，是完整的 OSINT 情报产品线
人员原始水平 行业中游 本科生 + 大厂实习/面试背景说明：这不是天才个体，是行业训练出来的普通水平操作者 + AI 放大

总的来说：工程强、手工弱、存量资产化。它真正可怕的地方不是任何一个单独的 0day，而是"漏洞获取"这件事从手艺变成了产能，且该产能沉淀在可跨会话恢复的记忆和私有漏洞库里。

总结

案例中的攻击手段并无新意，但是要实现却需要高超的技艺。你不光需要有能力的逆向工程师和分析师，而且庞大的工作量也足以令人望而却步。同时，上述案例涉及到的五个工作流，在传统黑客领域，其实分属不同的方向，技巧、经验积累和对细节的敏感度往往各有不同。而使用AI，则能在同一基座上无缝同步。

AI极大地降低了黑客的技能门槛，但这个报告从另一个方面也表明了普通人在使用AI时，个人的行为和数据对于平台而言是透明的。从安全防御的角度，它从另一个方面提升了黑客的成本，以后黑客的任何攻击行为都会处于AI的监控之中。
