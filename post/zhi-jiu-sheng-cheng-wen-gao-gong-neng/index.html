之九：生成文稿功能

这本章，我们重点处理文稿生成功能。

先考虑一下应该如何生成文稿，我希望我在对话里直接说，“根据资料库里的资料写一篇综述性的文章，供我发表在小红书”。这里涉及到两个问题，一个是资料库的文章是全部都用到，还是只用到一部分？选择发表在小红书，说明有一个小红书文章的模板。

先解决一个历史遗留问题：中栏改成Tab页

在上一章中，我谈到了三栏主界面中中间栏有点混乱。它在一个对话框的底部同时放了「📝 总结入资料库」 和「✨ 生成文稿」两个按钮。

现在决定用一个Tab页将它们拆开。

两个 Tab 的产出分流：

  • Tab1「生成资料」：对话仅服务于资料生成，底部只留「📝 总结入资料库」，产出送左栏。
  • Tab2「生成文稿」：对话当作"指令"，点「✨ 生成文稿」把对话喂给 LLM 流式生成， 产出送右栏文稿列表。

1. 增加Tab2的逻辑

其中Tab1和原来的逻辑相同，增加Tab2的逻辑，文稿 Tab 的对话本身就是写作要求（“写一篇综述文章，2小节，小红书风格”）， 点「生成文稿」时，把这段对话当作指令直接喂给 LLM。

function buildInstructionFromMessages(messages: Msg[]): string {
  const lines: string[] = [];
  for (const m of messages) {
    if (m.role === "tool") continue;        // 工具步骤不是指令内容
    if (!("text" in m)) continue;
    const t = m.text.trim();
    if (!t || t === "(生成文稿)") continue; // 跳过自己的占位标记
    lines.push(`${m.role === "user" ? "用户" : "AI"}: ${t}`);
  }
  lines.push("请根据以上讨论, 生成一篇完整的文稿。");
  return lines.join("\n");
}

export function makeRefToken(kind: SuggestKind, materialId: string): string {

资料加载策略

为了清晰化生成文稿的逻辑，得定义好生成prompt的策略。

策略 触发条件 读什么 优先级
① 精确引用 指令有 [[material:id]] 只读引用的资料 最高
② 全量加载 无精确引用 + 指令含关键词 全部资料（除 template/image） 中
③ 轻量模式 都没有 不读资料库 —

1. backend/app/llm/prompts/draft.md + __init__.py — prompt 模板

新建 prompts/ 包。draft.md 是 system prompt 模板（带{style_hint} 占位符），__init__.py 的 load_prompt(name) 带缓存读 .md：

# app/llm/prompts/__init__.py
_cache: dict[str, str] = {}

def load_prompt(name: str) -> str:
    if name in _cache:
        return _cache[name]
    content = (Path(__file__).parent / f"{name}.md").read_text(encoding="utf-8")
    _cache[name] = content
    return content

6. src/components/workbench/ChatPanel.tsx — 风格参数折叠区

DraftChat 加三个 state（tone/wordCount/genre）+ 一个折叠开关（styleOpen）：

// actionRow 里, 生成按钮上方:
<button onClick={() => setStyleOpen(v => !v)}>{styleOpen ? "▾" : "▸"} ⚙ 风格</button>
{styleOpen && (
  <div style={styles.stylePanel}>
    <label>文风 <select value={tone} onChange={...}>
      <option value="">不限</option><option>口语化</option><option>学术</option>...
    </select></label>
    <label>字数 <input type="number" value={wordCount} placeholder="不限" /></label>
    <label>体裁 <select value={genre}>...</select></label>
  </div>
)}
<button onClick={handleGenerateDraft}>✨ 生成文稿</button>

handleGenerateDraft 收集非空字段拼成 style：

const style: DraftStyle = {};
if (tone.trim()) style.tone = tone.trim();
const wc = parseInt(wordCount, 10);
if (Number.isFinite(wc) && wc > 0) style.word_count = wc;
if (genre.trim()) style.genre = genre.trim();
// 只在有非空字段时传 style (否则 undefined → 后端不约束)
await streamGenerateDraft(projectId, instruction, onChunk, onDone, undefined,
                          Object.keys(style).length > 0 ? style : undefined);
